Agentic Delivery Flow

How a user story moves from Azure DevOps to a deployed, tested Sitecore AI (XM Cloud) + Next.js component, and optionally to authored content. Each lane is a category of agents; numbers show the order of work.

Rules that apply across the flow
  • Every loop runs at most 3 rounds, then escalates to a human with a summary.
  • An agent never reviews its own work.
  • Agents pass work to each other as files (PRD, spec, task list, contract, bug list).
  • SonarQube and CodeQL in GitHub remain the final gate on the PR.
Systems involved
  • Azure DevOps: user stories and bugs
  • GitHub: code, PRs, SonarQube, CodeQL
  • Sitecore AI (XM Cloud) dev environment: items, test pages, content
  • Vercel: preview URLs and frontend deploys
